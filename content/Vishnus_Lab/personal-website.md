# Personal Website

This website you're currently browsing! Built with Hugo static site generator to create a fast, clean platform for sharing my thoughts and experiments.

## What it does

- **Thoughts Section**: Organized into observations and business teardowns with scrollable interface
- **Lab Section**: Showcase of projects and experiments with filtering and search
- **About Me**: Personal story and background
- **Contact**: Multiple ways to connect and collaborate

## Tech Stack

- **Static Site Generator**: Hugo for fast, secure, and maintainable site
- **Styling**: Custom CSS with CSS variables for theming
- **JavaScript**: Vanilla JS for interactive features
- **Hosting**: GitHub Pages with custom domain
- **Version Control**: Git with GitHub for collaboration

## Key Features

- **Responsive Design**: Works perfectly on all devices
- **Dark/Light Mode**: Automatic theme switching based on user preference
- **Fast Loading**: Static site generation ensures quick page loads
- **SEO Optimized**: Proper meta tags and structured data
- **Interactive Elements**: Search, filtering, and smooth animations

## Design Philosophy

Focused on simplicity and readability. The design prioritizes content over flashy elements, with clean typography and plenty of whitespace. The color scheme uses earthy greens and warm tones to create a welcoming, professional atmosphere.

## Lessons Learned

- **Hugo's Power**: Static site generators are incredibly powerful for content-focused sites
- **CSS Variables**: Using CSS custom properties makes theming and maintenance much easier
- **Performance Matters**: Users notice when sites load quickly
- **Content First**: Good content with simple design beats flashy design with poor content
